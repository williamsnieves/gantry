# implementing-css-modules-ui

Implements UI using the project's selected CSS Modules strategy.

The skill covers the roadmap evaluations:

```text
component module
global token need
dynamic runtime value
variant composition
deep selector smell
```

It focuses on scoped feature styles, semantic tokens, token-driven themes, explicit class variants, runtime CSS custom properties/inline styles, responsive layout, low specificity, stable selectors, focus/reduced-motion accessibility, and real-browser/visual evidence.

It does not select the styling profile or redesign the global token system.
