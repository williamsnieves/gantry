# testing-application-use-cases

Tests backend Application Use Cases with:

- real Domain objects and Domain Services;
- contract-faithful InMemory repositories;
- explicit provider-neutral stubs, spies, and fakes;
- deterministic clocks, IDs, and idempotency keys;
- state and Response DTO verification;
- meaningful negative side-effect assertions.

It excludes repository mocks, Domain mocks, real databases, provider SDKs, HTTP, composition, and Infrastructure-specific assertions.
