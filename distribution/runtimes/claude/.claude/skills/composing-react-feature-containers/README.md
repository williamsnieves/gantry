# composing-react-feature-containers

Composes React feature containers at route/feature boundaries.

It covers the exact roadmap evaluations:

```text
route container
modal feature
tiny component
Next.js server/client split
React Router loader
test container
```

The skill binds approved dependencies, routing/framework inputs, feature/server-state hooks, navigation, and presentational views while keeping business rules and Infrastructure out.

A valid result may be:

```text
NO_CONTAINER_REQUIRED
```

Container and view may also remain in the same file when that is the clearest proportional design.
