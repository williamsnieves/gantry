# integrating-headless-ui-primitives

Integrates accessible headless UI primitives into the project's shared UI and feature layers.

Supported examples include:

```text
Radix UI
Base UI
React Aria
Headless UI
shadcn/ui
native HTML primitives
```

The skill covers the exact roadmap evaluations:

```text
Dialog
Select / Combobox
Tooltip
Menu
Tabs
vendor accessibility override
portal layering
```

It preserves keyboard, focus, ARIA, dismissal, portals, disabled/invalid semantics, project tokens/variants, SSR/client boundaries, and nested-overlay behavior without moving business logic into shared UI.
