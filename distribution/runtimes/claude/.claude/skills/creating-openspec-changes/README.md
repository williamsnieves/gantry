# creating-openspec-changes

Creates a new, validated OpenSpec change from sufficiently clear context.

## Key Guardrails

- Discover the configured schema and workflow.
- Do not assume a fixed artifact sequence.
- Use official OpenSpec scaffolding.
- Never manually create a change directory as a shortcut.
- Do not implement code or mark tasks complete.
- Return to exploration when material decisions remain unresolved.

## Handoff

Consumes direct ready context or an `exploring-openspec-changes` brief.
Produces a change ready for review and later implementation.
