# recording-architecture-decisions

Records architecture decisions as durable ADRs.

Canonical ADR:

```text
ID
title
status
context
drivers
decision
alternatives considered
trade-offs
consequences
risks
revisit triggers
references
```

Allowed states:

```text
PROPOSED
ACCEPTED
SUPERSEDED
DEPRECATED
REJECTED
```

Core rule:

```text
decision recommendation
≠
accepted decision
```

Never mark `ACCEPTED` without authority.
