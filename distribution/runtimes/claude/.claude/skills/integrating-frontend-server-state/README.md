# integrating-frontend-server-state

Integrates the server-state strategy already selected by the project.

Profiles include:

```text
React Query
SWR
RTK Query
Apollo
Relay
framework loaders/actions
```

The skill covers query identities, cache ownership, deduplication, freshness, invalidation, mutations, optimistic rollback, dependent queries, route prefetch, SSR/hydration, retries, cancellation, error boundaries, security scope, and Application/adapter integration.

It explicitly covers the roadmap evaluations:

```text
duplicate requests
stale invalidation
optimistic rollback
dependent queries
route prefetch
adapter integration
```

It does not select a new library or rebuild a query cache/state machine inside custom hooks.
