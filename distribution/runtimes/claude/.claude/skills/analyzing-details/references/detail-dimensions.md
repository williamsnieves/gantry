# Detail Dimensions

Apply only relevant dimensions:

- scope, actors, ownership, and exclusions;
- required and optional inputs, defaults, validation, limits, ordering, and outputs;
- state transitions, retries, cancellation, cleanup, expiry, restart, and recovery;
- loading, empty, success, partial, error, disabled, unauthorized, accessibility, and localization states;
- schemas, nullability, migrations, events, APIs, generated clients, and source of truth;
- authentication, authorization, tenant isolation, logging, retention, and secrets;
- rollout, flags, observability, alerts, capacity, rollback, and support procedures;
- acceptance coverage, negative cases, integration contracts, and post-release checks;
- naming, docs, generated artifacts, dependencies, stale references, and ownership metadata.
