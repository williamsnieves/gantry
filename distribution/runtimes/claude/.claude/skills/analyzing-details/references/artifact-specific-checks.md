# Artifact-Specific Checks

Load only relevant sections.

## Story or Request
Actor, outcome, scope, business rules, acceptance criteria, constraints, questions, readiness.

## OpenSpec Proposal and Specs
Why, scope, exclusions, capabilities, delta semantics, complete requirements, observable scenarios, compatibility.

## Design
Decisions, rationale, alternatives, interfaces, data, migration, rollout, security, performance, reliability, and operations.

## Tasks
Coverage, dependency order, implementation, tests, docs, migration, operations, truthful completion state, no out-of-scope work.

## Code or Pull Request
All changed paths, callers, consumers, types, errors, cleanup, generated artifacts, tests, configuration, docs, description-to-diff consistency, release notes, and hidden unrelated changes.

## Documentation
Current behavior, commands, examples, names, paths, configuration, compatibility, and stale references.
