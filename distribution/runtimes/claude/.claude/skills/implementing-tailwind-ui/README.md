# implementing-tailwind-ui

Implements UI using the project's selected Tailwind conventions.

It covers the exact roadmap evaluations:

```text
long class list
repeated button classes
responsive variant
arbitrary token
dark mode
class conflict
```

The skill preserves semantic theme tokens, existing project primitives, explicit variants, responsive/container behavior, intentional class precedence, build-safe dynamic styling, accessibility, and real-browser/visual evidence.

It does not select Tailwind, introduce CVA/merge tooling, or redesign the global design-token system.
