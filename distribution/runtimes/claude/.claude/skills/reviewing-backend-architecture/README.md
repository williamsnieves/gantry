# reviewing-backend-architecture

Reviews whether backend architectural choices are correctly owned, proportionate, testable, operable, and safe to migrate.

It complements static architecture validation by challenging:

- unnecessary or missing abstractions;
- conceptual ownership;
- ports and adapters;
- Use Case and Domain design;
- composition and lifecycle;
- transactions, idempotency, and events;
- migration, reversibility, and drift;
- temporary seams and exit paths.

The skill reports decisions and findings; it does not refactor the code.
