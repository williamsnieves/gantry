# designing-responsive-layouts

Designs responsive frontend layouts by choosing the correct layout primitive and responsive context before implementation.

It covers the exact roadmap evaluations:

```text
dashboard grid
toolbar
card
mobile table
translated CTA
overflow regression
```

The skill distinguishes Flexbox, Grid, container queries, and viewport queries; derives thresholds from content failure points; preserves essential actions; supports translation, zoom/reflow, and logical properties; audits fixed dimensions; and fixes overflow structurally instead of hiding it.
