# designing-accessible-web-interfaces

Framework-agnostic accessibility-design skill based on WCAG 2.2.

It covers:

```text
Perceivable
Operable
Understandable
Robust
```

It defines semantics, accessible names and relationships, keyboard and focus behavior, status communication, visual accessibility, reflow, motion, target size, complex widgets, framework adaptations, and verification evidence.

The default engineering baseline is WCAG 2.2 Level AA unless another accepted target applies. The skill does not certify conformance, replace legal analysis, or treat automated scans as sufficient proof.
