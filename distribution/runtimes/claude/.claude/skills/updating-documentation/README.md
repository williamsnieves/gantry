# updating-documentation

Updates technical and project documentation to match approved current behavior.

## Rules

- Ground edits in project evidence.
- Map impact before editing.
- Validate commands, examples, links, fields, and defaults.
- Update generated docs through their source.
- Remove or deprecate stale guidance.
- Avoid unrelated rewrites.

## Provenance

Adapted from the approved LIDR `update-docs` reference and roadmap documentation standards.
