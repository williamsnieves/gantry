# Generated Documentation

Generated outputs must be changed through their authoritative source.

1. Identify source and generator.
2. Update source.
3. Discover the native generation command.
4. Regenerate without unrelated upgrades.
5. Inspect generated diff.
6. Run drift validation.

Do not manually patch generated output as the primary fix or accept unrelated churn.

If generation cannot run, report the blocker and do not claim the output is current.
