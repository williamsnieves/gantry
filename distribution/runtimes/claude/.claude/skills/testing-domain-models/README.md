# testing-domain-models

Creates pure unit tests for Entities, Value Objects, and Domain Services.

It covers:

- construction and invalid-state prevention;
- invariants and lifecycle transitions;
- equality and immutability;
- collection encapsulation;
- serialization;
- pure Domain calculations and decisions.

It forbids mocks, databases, HTTP, filesystems, providers, ORM, framework containers, composition, and implementation-detail assertions.
