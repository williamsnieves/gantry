# designing-system-architecture

Generates viable architecture candidates from accepted drivers and behavioral evidence.

Core rule:

```text
drivers + constraints
→ candidate architectures
```

Not:

```text
favorite technology
→ architecture
```

This skill does NOT select the winner.

Output:

```text
candidate-system-architectures.md
```
