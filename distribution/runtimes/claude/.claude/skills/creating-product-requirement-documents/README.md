# creating-product-requirement-documents

Creates a structured PRD from requirements discovery.

Core boundary:

```text
PRD
→ what / why / scope / constraints / outcomes

Architecture
→ system-level how
```

The skill preserves:

```text
provenance
uncertainty
conflicts
TBD metrics
constraint strength
open questions
```

and hands off to formal requirements and architecture work.

Output:

```text
product-requirements-document.md
```
