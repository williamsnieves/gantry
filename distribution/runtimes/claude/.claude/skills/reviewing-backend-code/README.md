# reviewing-backend-code

Reviews backend changes against the definitive standard using:

```text
auditing-code
+ reviewing-adversarially
+ analyzing-details
```

The skill prioritizes evidenced defects in correctness, architecture, security, data integrity, concurrency, idempotency, integrations, HTTP contracts, migrations, testing, and operability.

It excludes personal style findings, unrelated repository debt, fabricated validation evidence, and implementation work.
