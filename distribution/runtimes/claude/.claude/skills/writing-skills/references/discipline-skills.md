# Discipline-Enforcing Skills

Use this reference only when a skill exists to enforce a non-negotiable quality or safety behavior.

## Bright-Line Rules

Use direct language for requirements that cannot safely be optional.

State:

- the trigger;
- the mandatory action;
- prohibited shortcuts;
- the evidence required before proceeding.

## Pressure Testing

Test combined pressures such as:

- urgency;
- sunk cost;
- fatigue;
- requests to make an exception;
- claims that the case is too small;
- claims that the spirit is being followed.

Capture actual rationalizations from baseline tests and address only recurring, material loopholes.

## Ethical Constraint

Strong compliance language must serve the user's genuine quality or safety interest. Do not use false urgency, guilt, flattery, or manipulative claims.

## Red Flags

A discipline skill should define observable red flags that require stopping or restarting the procedure.

Do not use this pattern for ordinary guidance or reference skills.
