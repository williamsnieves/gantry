# writing-skills

Creates, revises, and evaluates agent skills using a RED–GREEN–REFACTOR authoring cycle.

## Runtime

`SKILL.md` is the only default runtime file.

## Conditional References

- `authoring-methodology.md`: substantial creation or restructuring.
- `discovery-and-frontmatter.md`: activation and naming.
- `progressive-disclosure.md`: file organization and context reduction.
- `testing-methodology.md`: evaluations and regressions.
- `discipline-skills.md`: non-negotiable behavior only.

## Evaluation

The `evals/` directory is excluded from normal runtime context.

## Provenance

Adapted from the approved roadmap references, especially LIDR SpecBoot's `writing-skills`, Anthropic's skill authoring guidance, AgentSkills.io, Mgechev's skill best practices, and Addy Osmani's agent skill patterns.
