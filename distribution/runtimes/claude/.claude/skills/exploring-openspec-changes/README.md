# exploring-openspec-changes

Investigates unclear or risky changes before OpenSpec artifacts are created.

## Runtime

`SKILL.md` is the default runtime file.

## Key Boundary

This skill reads and reasons. It does not create a change folder, write proposal/spec/design/task artifacts, or modify code.

## Handoff

Its output is consumed by `creating-openspec-changes` or may recommend editing an active change, exploring further, or stopping.

## References

The skill is based on the approved OpenSpec `explore`, workflow, overview, command behavior, and existing-project documentation from the roadmap.
