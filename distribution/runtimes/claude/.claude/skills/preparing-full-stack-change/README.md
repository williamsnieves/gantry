# preparing-full-stack-change

Full-stack preparation orchestrator.

Roadmap workflow:

```text
enrich request
→ explore OpenSpec
→ create/edit change
→ identify backend and frontend slices
→ plan contracts and sequence
→ hand off to stack-specific skills
```

Core rule:

```text
stabilize shared contracts first
→ then allow stack-local implementation decisions
```

This skill stops before code implementation.
