# enriching-user-stories

Analyzes and enriches software stories and change requests before specification or planning.

## Runtime

`SKILL.md` is the only default runtime file.

## Conditional References

- `readiness-dimensions.md`: completeness assessment.
- `gap-classification.md`: blocker, assumption, risk, and scope classification.
- `acceptance-criteria.md`: observable criteria.
- `context-retrieval.md`: project evidence retrieval only when necessary.

## Key Constraint

The skill may clarify, structure, and expose missing decisions. It must not invent product or architecture decisions.

## Provenance

Adapted from the approved LIDR SpecBoot `enrich-us` reference and the harness skill-authoring artifacts.
