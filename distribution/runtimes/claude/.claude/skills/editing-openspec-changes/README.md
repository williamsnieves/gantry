# editing-openspec-changes

Revises active OpenSpec changes as living plans.

## Core Decisions

- Edit in place when the same intent is refined.
- Create a new change when intent fundamentally changes or independent scope emerges.
- Propagate every material revision through dependent artifacts.
- Keep task status truthful.
- Reconcile code and artifacts only after determining the approved source of truth.

## Boundary

This skill edits active change artifacts. It does not create new changes, implement tasks, sync main specs, or archive changes.
