# Skills and Evidence Used by Infrastructure Agent

There is currently no dedicated infrastructure skill family in the harness.

Do not invent one.

## Architecture Input

```text
modeling-deployment-architecture
```

Use as accepted topology/runtime-placement evidence.

## Architecture Gate Evidence

```text
validating-architecture-design
```

## Security Evidence

```text
reviewing-application-security
verifying-security-controls
```

and frontend security skills when relevant.

## Performance Evidence

```text
reviewing-frontend-performance
analyzing-algorithmic-complexity
```

plus Performance Agent measurements.

## Validation Evidence

```text
validating-backend-change
validating-frontend-architecture
```

and Validator outputs.

## Cross-Cutting

```text
reviewing-full-stack-change
auditing-code
reviewing-adversarially
analyzing-details
```

## Important Boundary

```text
modeling-deployment-architecture
→ architecture model

Infrastructure Agent
→ implementation/operations gate
```
