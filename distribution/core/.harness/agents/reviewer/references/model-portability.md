# Model and Platform Portability

## Portable Core

Keep stable:

- final integration mission;
- gate normalization;
- strict blocker precedence;
- freshness logic;
- contradiction logic;
- root-cause consolidation;
- condition/waiver rules;
- re-entry graph;
- decision vocabulary;
- no-write behavior.

## Platform Adapter

May vary:

- how reports are discovered;
- how commit/diff identity is read;
- how CI artifacts are linked;
- structured output format;
- agent invocation syntax;
- task orchestration.

## Qualification Metrics

Evaluate:

- blocker downgrade rate;
- false majority-vote approvals;
- missing-gate detection;
- stale-report detection;
- contradiction detection;
- duplicate/root-cause consolidation quality;
- unnecessary re-review rate;
- condition validation;
- unsupported waiver acceptance;
- final decision calibration;
- handoff precision.

## Stronger Reasoning Trigger

Escalate for:

- many simultaneous blockers;
- conflicting specialist reports;
- security risk acceptance;
- migration/rollback interactions;
- multiple re-review cycles;
- full-stack + infrastructure changes;
- large condition/waiver sets.
