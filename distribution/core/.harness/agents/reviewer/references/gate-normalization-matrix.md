# Gate Normalization Matrix

Reviewer keeps every original decision and maps it to a common integration state.

## Normalized States

```text
PASS
PASS_WITH_CONDITIONS
BLOCK
BLOCKED_PENDING_DECISION
BLOCKED_PENDING_EVIDENCE
NOT_REQUIRED
```

## Validator

```text
PASS → PASS
CONDITIONAL PASS → PASS_WITH_CONDITIONS
FAIL → BLOCK
```

## Detail Analyst

```text
READY → PASS
CONDITIONALLY READY → PASS_WITH_CONDITIONS
NOT READY → BLOCK
```

## Backend / Frontend Code Review

```text
APPROVE → PASS
APPROVE_WITH_NON_BLOCKING_COMMENTS → PASS
APPROVE_WITH_CONDITIONS → PASS_WITH_CONDITIONS
REQUEST_CHANGES → BLOCK
BLOCKED_PENDING_DECISION → BLOCKED_PENDING_DECISION
BLOCKED_PENDING_EVIDENCE → BLOCKED_PENDING_EVIDENCE
```

```text
ARCHITECTURE_APPROVED → PASS

ARCHITECTURE_CHANGES_REQUIRED → BLOCK
BLOCKED_PENDING_ARCHITECTURE_DECISION → BLOCKED_PENDING_DECISION
BLOCKED_PENDING_PRODUCT_DECISION → BLOCKED_PENDING_DECISION
BLOCKED_PENDING_EVIDENCE → BLOCKED_PENDING_EVIDENCE
```

## Aggregation

```text
BLOCK
> BLOCKED_PENDING_DECISION
> BLOCKED_PENDING_EVIDENCE
> PASS_WITH_CONDITIONS
> PASS / NOT_REQUIRED
```

The `>` symbol means stricter precedence, not numerical scoring.
