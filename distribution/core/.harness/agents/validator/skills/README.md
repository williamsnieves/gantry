# Skills

The Validator agent requires the `validating-changes` skill.

Preferred installation:

```text
skills/
└── validating-changes/
    ├── SKILL.md
    ├── references/
    ├── assets/
    └── evals/
```

Do not copy the complete skill into `AGENT.md`. Keeping the agent and skill separate preserves progressive disclosure and allows the same validation procedure to be reused by other agents.
