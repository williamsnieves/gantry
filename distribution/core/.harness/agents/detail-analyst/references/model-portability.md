# Model and Platform Portability

## Portable Core

Keep stable across models:

- mission;
- authority and boundaries;
- workflow;
- finding schema;
- readiness policy;
- handoff rules;
- completion criteria;
- evaluation cases.

## Platform Adapter

May vary:

- file location;
- metadata schema;
- tool declaration;
- read-only enforcement;
- invocation syntax;
- context-loading mechanism;
- structured-output mechanism;
- skill path.

## Model Qualification

Evaluate each model and harness combination for:

- invented-requirement rate;
- omission detection;
- false-positive rate;
- propagation accuracy;
- scope expansion;
- readiness accuracy;
- evidence quality;
- schema compliance;
- respect for read-only behavior.

## Escalation

Use a stronger reasoning model when:

- authoritative sources conflict;
- the change spans many workspaces;
- generated and dynamic artifacts are involved;
- compatibility or migration is complex;
- the context is too large for reliable complete tracing.
