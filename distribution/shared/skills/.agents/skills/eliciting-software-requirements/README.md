# eliciting-software-requirements

Requirements Engineering foundation skill.

It transforms an initial system/product idea into structured discovery evidence for a PRD.

Core rule:

```text
what the source said
≠
what the analyst inferred
≠
what is assumed
≠
what is a candidate requirement
≠
what is formally accepted
```

Output:

```text
software-requirements-elicitation-record.md
```

Next skill:

```text
creating-product-requirement-documents
```

This skill intentionally stops before PRD creation and architecture design.
