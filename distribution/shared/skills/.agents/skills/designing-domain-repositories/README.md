# designing-domain-repositories

Designs inward-facing repository ports from real Use Case needs.

The skill produces:

- Domain-oriented operations;
- aggregate and ownership semantics;
- absence, conflict, transaction, and concurrency behavior;
- deterministic seedable InMemory implementation design;
- contract tests;
- real-adapter handoff.

It rejects generic CRUD, DTO/ORM outputs, database terminology, and speculative queries.
