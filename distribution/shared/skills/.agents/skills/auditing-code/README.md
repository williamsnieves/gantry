# auditing-code

Performs evidence-based, multi-dimensional code audits.

## Core Boundary

This skill identifies and prioritizes risks. It does not implement fixes, replace mechanical validation, or claim dedicated dead-code proof.

## Audit Dimensions

- architecture and flow;
- correctness and type safety;
- security and dependencies;
- performance and resources;
- maintainability and dead-code risk.

## Key Rules

- Define scope before scanning.
- Treat tools as candidate generators.
- Require evidence for findings.
- Separate severity and confidence.
- Group symptoms by root cause.
- State limitations honestly.
