# defining-functional-requirements

Formalizes PRD behavior into a stable functional requirements catalog.

Core rule:

```text
product intent
→ atomic observable behavior
→ traceable functional requirement
```

Not:

```text
product intent
→ API/framework/architecture design
```

Output:

```text
functional-requirements-catalog.md
```

```text
defining-non-functional-requirements
```
