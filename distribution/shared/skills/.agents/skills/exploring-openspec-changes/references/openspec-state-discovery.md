# OpenSpec State Discovery

## Discover Configuration

Inspect the project OpenSpec setup rather than assuming a fixed profile or artifact sequence.

Determine:

- OpenSpec location;
- configured profile or schema where available;
- specification locations;
- active change locations;
- project-specific conventions;
- available commands or actions.

## Inspect Specifications

Identify specifications related to:

- current behavior;
- desired behavior;
- affected capabilities;
- shared contracts;
- potentially conflicting requirements.

Do not assume absent documentation means absent behavior.

## Inspect Active Changes

Check for:

- identical intent;
- overlapping capability;
- dependency;
- conflict;
- superseded direction;
- work that can complete independently.

Recommend editing an existing change only when it genuinely owns the same intent.

## Evidence Record

For each relevant item, record:

- path or identifier;
- relationship to the problem;
- implication for scope or approach.
