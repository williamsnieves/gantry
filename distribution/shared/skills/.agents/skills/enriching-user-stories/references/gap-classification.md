# Gap Classification

Classify every material gap into exactly one primary category.

## Blocking Question

A decision or fact required before safe specification or implementation.

Examples:

- unclear source of truth;
- incompatible business rules;
- undefined authorization behavior;
- missing contract ownership.

## Non-Blocking Clarification

Useful detail that improves precision but can be resolved during normal planning without changing the core outcome.

## Assumption

A provisional interpretation used only when necessary.

Every assumption must:

- be explicit;
- explain its impact;
- be easy to confirm or reject;
- never be presented as an approved decision.

## Risk

A plausible negative outcome requiring mitigation, review, or validation.

## Discoverable Context

Information expected to exist in canonical project sources. Retrieve it rather than asking the user when access is available.

## Out-of-Scope Discovery

Related work that should not expand the current request. Record it separately.

## Duplicate or Irrelevant Detail

Content that does not improve understanding, implementation, or verification. Exclude it from the enhanced story.
