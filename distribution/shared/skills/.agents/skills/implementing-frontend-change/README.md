# implementing-frontend-change

Frontend implementation orchestrator.

Roadmap workflow:

```text
apply standard
→ classify profile
→ plan vertical slices
→ select domain/application work
→ implement adapters
→ implement hooks/components
→ apply styling profile
→ test
→ validate accessibility and architecture
→ review
```

The central constraint is:

```text
orchestrate focused skills
≠
duplicate focused-skill rules
```

The goal is the smallest complete skill graph for a specific change.
