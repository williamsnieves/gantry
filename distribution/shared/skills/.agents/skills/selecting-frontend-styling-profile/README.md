# selecting-frontend-styling-profile

Selects and documents the frontend styling strategy for a project, package, capability, or feature.

It determines:

```text
primary styling system
hybrid boundaries
primitive ownership
token source
variants
themes
responsive behavior
accessibility baseline
exceptions and migration
```

It does not implement styles, introduce a new system, ban Tailwind universally, force CSS Modules universally, or promote feature UI to shared based only on appearance.
