# adapting-backend-rules-to-existing-code

Adapts the definitive backend standard to one brownfield change without forcing a repository-wide rewrite.

Required outputs:

```text
current-state map
target-state map
change-local rules
migration seams
debt ledger
```

The skill protects existing behavior, introduces safe seams, prevents new or worsened drift, governs temporary deviations, and treats security, data integrity, transactions, and compatibility as explicit decisions rather than ordinary debt.
