# managing-frontend-design-tokens

Governs and evolves frontend design tokens across:

```text
palette/base values
semantic tokens
component tokens
themes
vendor mappings
deprecations
local one-off values
```

It covers the exact roadmap evaluations:

```text
dark mode
danger color
spacing scale
vendor token mapping
deprecated token
local one-off value
```

The skill emphasizes stable semantic meaning, one source of truth, accessibility/contrast, bounded scales, safe migration, shallow aliases, and restraint against token-per-pixel proliferation.
