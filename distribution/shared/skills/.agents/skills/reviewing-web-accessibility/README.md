# reviewing-web-accessibility

Performs an evidence-based accessibility review of an implemented web interface.

It covers the exact roadmap evaluations:

```text
focus trap
color-only error
missing label
reduced motion
mobile target size
screen-reader status
```

Outputs are structured around:

```text
violation
→ user impact
→ reproduction
→ severity
→ recommended fix
→ verification plan
```

Automated scans are evidence, not proof of WCAG conformance.
