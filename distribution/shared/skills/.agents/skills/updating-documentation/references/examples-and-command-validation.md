# Examples and Command Validation

## Commands

Verify command existence, working directory, runtime, package manager, flags, prerequisites, and expected effect from repository evidence. Never invent conventional commands.

## Code and Configuration

Verify imports, APIs, types, fields, async behavior, defaults, required status, environment scope, and secret handling.

Examples must not expose secrets, use production credentials, recommend insecure defaults, or hide destructive behavior.

Validate through repository-supported execution, compilation, schema checks, fixtures, or documentation tests. If verification is impossible, report the limitation.
