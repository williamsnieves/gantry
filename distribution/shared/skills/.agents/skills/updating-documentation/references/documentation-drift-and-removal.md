# Documentation Drift and Removal

Drift includes obsolete behavior, commands, paths, defaults, screenshots, diagrams, compatibility claims, broken links, and duplicate conflicting guidance.

Remove content when behavior no longer exists and no supported audience needs it. Deprecate when compatibility, migration, rollback, or supported older versions still require it.

Update indexes, navigation, anchors, inbound links, examples, diagrams, support references, and search metadata after removal or rename.

Do not treat wording differences as drift without checking semantics and audience.
