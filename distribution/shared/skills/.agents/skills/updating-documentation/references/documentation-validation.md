# Documentation Validation

1. Review the full documentation diff.
2. Confirm impact coverage.
3. Check terminology and cross-document consistency.
4. Validate commands, examples, schemas, generated output, links, anchors, formatting, and project-required doc tests.
5. Confirm obsolete guidance is removed or deprecated.
6. Confirm unrelated content remains stable.

Statuses:

- Complete: all affected surfaces updated and validation passes.
- Conditionally complete: bounded validation remains with owner and follow-up.
- Incomplete: behavior is not fully documented, examples are unverified, generated output is stale, or validation fails.
