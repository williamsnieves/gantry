# implementing-frontend-repository-adapters

Implements accepted frontend repository ports using HTTP, BFF, IndexedDB, browser storage, cache, or offline persistence.

The skill owns external types, mapping, runtime validation, stable failure semantics, cancellation, pagination, storage lifecycle, and faithful boundary tests.

It prevents raw payloads, transport errors, browser handles, provider enums, and business rules from leaking into Application, Domain, hooks, or components.
