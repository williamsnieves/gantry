# analyzing-algorithmic-complexity

Cross-cutting skill for frontend, backend, and the future Performance Agent.

It analyzes:

```text
time complexity
space complexity
real input bounds
execution frequency
hidden multiplicative work
data-structure choices
amortized/worst-case behavior
CPU vs I/O/database/network/rendering bottlenecks
before/after complexity
benchmark/profile evidence
```

Core principle:

```text
Big O identifies scalability risk.
Real input size + profiling determine optimization priority.
```

It deliberately does not belong only to frontend or backend.
