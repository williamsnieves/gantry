# testing-react-components

Implements user-centered React component tests.

The skill focuses on:

```text
accessible roles and names
user interactions
loading / empty / error / success
forms
keyboard and focus
status communication
semantic dependency injection
representative HTTP-backed UI behavior
```

It avoids private React state, setter calls, hook/library internals, brittle DOM structure, incidental CSS classes, global fetch mocks, arbitrary sleeps, all-state snapshots, and duplicate lower-level coverage.
