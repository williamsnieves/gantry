# reviewing-application-security

Cross-cutting implementation security review skill.

Knowledge model:

```text
STRIDE
→ architecture threat discovery

OWASP Top 10:2025
→ broad application-risk classification

MITRE CWE / CWE Top 25:2025
→ concrete weakness/root-cause classification

OWASP ASVS 5.0.0
→ downstream control verification
```

This skill does not treat the standards as duplicate checklists and does not use CWE rank as finding severity.
