# designing-accessible-forms

Designs accessible web-form contracts before implementation.

It covers the exact roadmap evaluations:

```text
required field
async validation
server error
dynamic fields
date range
multi-step form
```

The skill defines labels, descriptions, required/optional semantics, groups, validation ownership/timing, field errors, error summaries, submission state, async validation race safety, server-error mapping, dynamic-field focus/identity, date ranges, multi-step focus/progress, and verification.

It keeps UI shape/interaction validation separate from Domain/backend business invariants.
