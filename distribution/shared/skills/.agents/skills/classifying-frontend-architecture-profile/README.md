# classifying-frontend-architecture-profile

Chooses the lightest valid frontend architecture profile:

```text
Profile A — simple feature/application
Profile B — modular frontend
Profile C — package-scale product/monorepo
```

The skill evaluates behavior, client/server authority, Domain and Application justification, ports, consumers, ownership, testability, deployment, and evolution.

It prevents both ceremonial overengineering and complex client-owned behavior remaining trapped in an insufficiently structured feature.
